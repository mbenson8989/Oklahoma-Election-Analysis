# Oklahoma Election Analysis: 2022 vs 2026 Governor Race, ΔG Method and Reverse Factoring (STAGED, not published)

County-level analysis of the Oklahoma governor race, 2022 (official) vs 2026 (\*marked UNOFFICIAL by project rule; Oklahoma State Election Board county export, data last updated 11/06/2026), all 77 counties, with 2024 presidential as context. Method developed by Morissa Benson; it began with the [Cedar County Audit](https://github.com/mbenson8989/Nebraska-Election-Analysis-/wiki/Cedar-Audit).

- `OK_Governor_2022_2026_County_ReverseFactoring.csv`: all 77 counties, largest to smallest population
- `OK_results_summary.json`: Oklahoma constant k_OK, forward/backward statewide solve, fitted constants, floor/ceiling, counts
- `*.png`: charts used on the wiki
- `scripts/run_all.sh`: fetch, pass A, pass B, compare, analysis, charts, wiki build, wiki number check
- `verification/`: start with `VERIFICATION.md` (3,080 county figures, 0 mismatches)
- `sources/`: raw Board exports and registration PDFs

These files measure a pattern; they make no claim about intent, fraud or cause.
